# HeekiWord

**영단어 암기 앱** - 쉽고 즐겁게 배우는 영단어

## 📋 프로젝트 개요
HeekiWord는 영단어를 체계적으로 학습할 수 있도록 설계된 웹 기반 암기 앱입니다.

## 🎯 주요 기능
- 플래시카드 학습
- 단어 퀴즈
- 진도 추적
- 즐겨찾기 관리

## 📁 폴더 구조
```
heekiword/
├── README.md          # 프로젝트 설명
├── docs/              # 기획/디자인 문서

│   ├── html/          # HTML 페이지
│   ├── css/           # 스타일
│   ├── js/            # 자바스크립트
│   └── assets/        # 이미지, 폰트 등
└── public/            # 배포 파일
```
